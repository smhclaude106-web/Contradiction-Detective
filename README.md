# 진술서 탐정 (Contradiction Detective)

고등학교 1학년 영어 수업용 추리 게임입니다. 학생들은 용의자들의 영어 진술과 사건 파일을 비교해 **동시에 사실일 수 없는 두 문장**을 찾아 OBJECTION!을 외치고, 증거를 모아 범인을 지목합니다.

## 바로 플레이

GitHub Pages 주소로 접속하면 PC, 교실 TV, 스마트폰 브라우저에서 바로 플레이할 수 있습니다. 설치나 로그인은 필요 없습니다.

## 학습 포인트

- 세부 정보 대조 독해 (수능 내용 일치)
- 시제와 시간 관계: 과거완료 had p.p.
- 관계사절이 꾸미는 대상 파악 (지칭 추론)
- 가정법 과거완료의 실제 의미 (함정 문장)
- 결론 문장 배열로 짧은 영어 출력 연습

## 게임 흐름

1. 나비 경감의 사건 브리핑과 용의자 소개
2. 증거 보드(사건 파일)와 심문실(진술) 조사
3. 모순되는 두 문장을 골라 OBJECTION! 맞히면 증거 카드, 틀리면 신뢰도 하트 감소
4. 증거를 모두 모으면 범인 지목
5. 영어 사건 보고서 문장 완성
6. 등급(S/A/B/C)과 문법 포인트 정리

## 새 사건 만들기 (교사용)

- `index.html` 상단의 `CASE` 데이터를 고치거나,
- 게임 타이틀 화면의 **사건 불러오기** 버튼에 사건 JSON을 붙여넣으면 됩니다.

용의자 외모(`look`)는 빼도 되며, 없으면 이름에 맞춰 자동으로 그려집니다.

## 기술

외부 라이브러리 없는 HTML 파일 하나입니다. 캐릭터는 SVG, 효과음은 Web Audio API로 직접 만들었습니다. 진행 상황은 각 브라우저에 저장됩니다.
